# E-commerce Doce Mila (React + Vite)

Este é o projeto corrigido e pronto para execução.

## Como Executar

1. Extraia o ficheiro `.zip`.
2. Abra o terminal na pasta raiz do projeto.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra o navegador no endereço indicado no terminal (ex: `http://localhost:3000`).
